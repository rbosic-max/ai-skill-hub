# AI Skill Hub

Centralno mjesto za upute, skilove i nadzor nad Claude, ChatGPT i Gemini.

## Pravilo br. 1
Svaka promjena upute ide prvo ovdje, pa tek onda u alat.
Tako nikad ne izgubiš "koja je verzija gdje".

## Mapiranje alata
| Alat     | Mehanizam              | Gdje u projektu        |
|----------|------------------------|------------------------|
| Claude   | Skills (SKILL.md)      | 01-CLAUDE/             |
| ChatGPT  | Custom Instructions + GPTs | 02-CHATGPT/        |
| Gemini   | Gems + prilagođene upute | 03-GEMINI/           |

## Tok rada (iteracija)
1. Zadatak → model odradi
2. Ti pregledaš rezultat (00-NADZOR/dnevnik-iteracija.md)
3. Ako šteka → popraviš uputu u odgovarajućoj mapi
4. Ažuriraš verziju u dnevniku
5. Ponovi
